## 🌟 Featured Projects

### 👁️ Optsam Eye Care — Clinic Website

<div align="center">

**[🌐 LIVE SITE](https://galaxymushi.github.io/optsam-eye-care-website/)** · **[📦 Source Code](https://github.com/galaxymushi/optsam-eye-care-website)** · **[💬 ASK Optsam](https://github.com/galaxymushi/askoptsam)**

</div>

Tovuti rasmi ya **Optsam Eye Care & Optical Workshop** — kliniki ya macho na karakana ya miwani iliyopo Mbagala, Dar es Salaam. Tovuti inawasilisha huduma za macho, miwani, kazi za jamii na taarifa za mawasiliano kwa Kiswahili na Kiingereza.

**✨ Vipengele Mkuu:**

| Category | Details |
|----------|---------|
| ⚡ **Performance** | Static Astro 5 build, self-hosted fonts, zero tracking |
| 📱 **Responsive** | Mobile-first layout for patients on any device |
| 📝 **Content** | Blog with Swahili eye-health posts, community outreach gallery |
| 🔍 **SEO** | Canonical URLs, Open Graph previews, custom 404 |
| ✉️ **Enquiry** | Privacy-friendly contact form — composes email/WhatsApp locally |

**🏗️ Tech Stack:** Astro 5 · TypeScript · Sharp · GitHub Pages

**Related:** **[ASK Optsam](https://github.com/galaxymushi/askoptsam)** — bilingual (English / Kiswahili) eye-health information MVP built with Astro.

### 🏠 KodiSalama — Property Management SaaS (v1.3.0)

<div align="center">

**[🌐 LIVE APP](https://kodisalama.vercel.app)** · **[📦 Source Code](https://github.com/galaxymushi/kodisalama)** · **[📋 Releases](https://github.com/galaxymushi/kodisalama/releases)**

</div>

Mfumo kamili wa **multi-tenant SaaS** wa usimamizi wa kodi za nyumba kwa wamiliki wa nyumba nchini Tanzania. Kila mmiliki ana akaunti yake na data zake zimejitengwa kabisa.

**✨ Vipengele Mkuu:**

| Category | Features |
|----------|----------|
| 👤 **Multi-Tenant** | Wamiliki wengi, data isolation kwa ownerId, open registration |
| 💬 **SMS Gateway** | Africa's Talking integration, risiti & vikumbusho moja kwa moja |
| 📜 **Legal Compliance** | Sera ya Faragha, Masharti ya Matumizi, mandatory acceptance |
| 🏢 **Property Mgmt** | Vyumba, wapangaji, occupancy tracking, deposits |
| 💰 **Payments** | Cash, M-Pesa, Tigo Pesa, Airtel, benki, period tracking |
| 📊 **Dashboard** | Mapato, collection rate, top debtors, analytics |
| 📄 **Contracts** | Mikataba rasmi yenye bendera ya Tanzania 🇹🇿 |
| 🔐 **Security** | Scrypt password hashing, per-account isolation, rate limiting |

**📈 Milestones:**
- ✅ v1.0.0 — Initial release (Oct 2026)
- ✅ v1.1.0 — Multi-tenant conversion (Oct 2026)
- ✅ v1.2.0 — SMS Gateway integration (Oct 2026)
- ✅ v1.3.0 — Legal pages + mandatory acceptance (Oct 2026)

**🏗️ Tech Stack:** Next.js 16 · TypeScript · PostgreSQL (Neon) · Drizzle ORM · Vercel · Tailwind CSS · Africa's Talking API
